# 性能、架构与运行优化待办

## 目标与基线

- 首屏减少无效高优先级资源和非浏览功能代码。
- Node.js / Docker 降低公共数据与静态资源的传输、压缩和日志成本。
- SQLite 提供可预览、可备份、显式执行的安全维护能力。
- 保持 SQLite / Redis 共用 API、`revision` 乐观锁和当前文档聚合模型。

审查基线：

- 首页 2.5 秒内发出 3 个 Fetch、11 个脚本和 23 个图片请求。
- 图片传输约 935 KiB；9 张图片为 eager，其中 5 张位于首屏以下。
- 首屏预加载 JavaScript 约 112.0 KiB gzip。
- `public_data` 为 90,676 字节；gzip 32,062 字节，Brotli 26,599 字节。
- `data/local.db` 为 40.86 MiB，空闲页占 65.8%，存在 130 个未引用旧媒体。
